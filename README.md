# DRAC_workflows
Workflows for sequence analysis created to work on a generic profile on Digital Research Alliance Canada.

# euk_MAG_DRAC
A metagenome genome assembly pipeline optimised for detecting eukaryotic genomes / genome fragments.

# mag_DRAC
A metagenome genome assembly pipeline optimised to detecting prokaryotes. 

# humann_DRAC
A functional analysis pipeline for metagenomes based on BioBakery's humann / metaphlan. Patches some compatibility issues between metaphlan, humann and DRAC.
